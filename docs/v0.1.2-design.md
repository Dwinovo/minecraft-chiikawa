## 2. 除草证

### 2.1 原作与取舍

- 原作里有好几种资格：除草资格（草むしり検定）、お酒の資格、スーパーアルバイター、驾照。考到资格报酬会提高，除草资格考过后负责的区域也会变（[キャラクターノート](https://character-note.com/archives/1370)）。
- 除草资格按级别分，级别越小越高。吉伊考了三次才过 5 级（[KAI-YOU](https://kai-you.net/article/92836)），乌萨奇早就是高级（[KAI-YOU](https://kai-you.net/article/92874)）；栗子馒头持有お酒の資格，狮萨在学。
- **不照搬原作的等级**：剧情大家都知道，照抄就没有玩头。我们要的是"考证"这件事本身：每个角色都能考，只是各有长短；等级是在游戏里一点点考出来的。
- 网上流传的"7 道四选一"考题是粉丝自编的模拟题，不采用；宠物考试也不出题，只算通过率。
- **主人替宠物报名**：最初的设计是每 7 天一个考试日，宠物自己去公告板考。做出来以后，玩家看不出它考没考、考过没有，像是一直在干活。改成主人在考试桌报名、交钻石、选哪只去考，有一种家长帮忙报名的感觉；公告板上和考试有关的东西全部去掉。

### 2.2 规则

所有数字都在数据里，下表是默认值：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 等级 | 5 级到 1 级，1 级最高 | 没证的宠物先考 5 级；一次只考下一级 |
| 初始等级 | 没有 | 驯服的、刷怪蛋出来的、复活的都不会凭空有证 |
| 野生宠物 | 按角色倾向随机 | 多数没有，少数带 5 级或 4 级，极少数更高；野生宠物不考试 |
| 报名时间 | 白天 7:00 到 15:00 | 晚了来不及考 |
| 报名费 | 1 颗钻石 | 报名时从主人身上扣；错过、拆桌都不退 |
| 一张桌子 | 一次一只 | 椅子上方被挡住时不能报名 |
| 谁能报名 | 主人自己的、48 格内的宠物 | 坐下的不去；够不着的不去，范围和它领工作牌一样 |
| 报考条件 | 上次考试后完成过至少 1 张除草牌 | 还没到 1 级；没有在等的考试或结果 |
| 截止 | 17:00 还没坐下答卷就算错过 | 这次作废，练习和读书的加成保留 |
| 基础通过率 | 5 级 40%、4 级 30%、3 级 22%、2 级 15%、1 级 8% | 越往上越难 |
| 练习 | 上次考试后每完成一张除草牌 +3%，最多 +30% | 只算公告板的除草牌，自己随手除草不算 |
| 读书 | 读过参考书 +25%，考完用掉 | 一次只能读一本：读过还没考的，再给参考书不收 |
| 越挫越勇 | 每落榜一次 +5%，最多 +20%，考过清零 | 屡败屡考，最后总能过 |
| 角色倾向 | 以上加总后乘以角色的系数 | 见下；最终通过率不超过 95% |
| 出结果 | 交卷时算好，第二天日出公布 | 中午还没去看、或者桌子没了，就地揭晓 |

**角色倾向**（性格数据，按原作的性格来定，但不写死结局）：

| 角色 | 通过率系数 | 没考过时 | 依据 |
| --- | --- | --- | --- |
| 吉伊 | 0.7 | 哭 | 很想考，但一紧张就考砸 |
| 小八 | 0.8 | 困惑 | 和吉伊一样想考，通过率比吉伊高一点 |
| 乌萨奇 | 1.4 | 困惑 | 随性，一去就能过 |
| 狮萨 | 1.1 | 困惑 | 认真努力；它最想考的是之后的饮酒证 |
| 飞鼠 | 0.6 | 困惑 | 不爱干活，更不爱考试 |
| 栗子馒头 | 0.9 | 困惑 | 慢悠悠，不着急 |
| 獭师父 | 1.1 | 困惑 | 什么都做得好 |
| 古本屋 | 1.0 | 困惑 | 书多，读书加成额外 +10% |

例：吉伊考除草证 5 级，没读书、练了 5 次、落榜过 1 次，通过率 (40% + 15% + 5%) × 0.7 = 42%。

**除草证的作用：**

- 等级越高，除草报酬越多：每升一级多 1 个绿宝石，1 级比没证多 5 个。
- **高级除草牌**：公告板升到 2 级才会贴（和讨伐牌一样）；只有除草证 3 级以上的宠物能领；工作量是普通除草牌的两倍（16–32 棵），报酬是普通的 2.5 倍，同样受等级加成。

### 2.3 考试桌

- 一张课桌连着后面的椅子，占两格，像床一样一起放、一起拆，只有桌子那一半掉落。配方：木台阶 ×3 放上排，下排木棍、纸、木棍。
- 右键任一半打开报名界面：主人附近的宠物各占一行，写着它要考几级、通过率（鼠标悬停看基础、练习、越挫越勇、读书、角色系数各是多少），或者它为什么不能去。选一只，按"报名"交钻石。
- 桌上显示这张桌子的状态：有宠物报了名、还没交卷时放着答题纸；第二天早上换成结果单，通过是红圈，没过是红叉；到中午收走。
- 界面最上面一行写这张桌子现在能不能报名，不能时写原因（不在报名时间、已经有宠物在考、椅子上方被挡住），有宠物在考时写它考的是几级、交没交卷。
- 拆掉桌子，正在考的宠物这次作废（钻石不退）；已经交了卷的，第二天就地揭晓。

### 2.4 考试的样子

**考试当天：** 报了名的宠物自己走到椅子上坐下，面向桌子，写约 26 秒（每只随机浮动几秒），交卷，再坐一秒才起来。主人的聊天栏会收到"报名了""交卷了，结果明天早上出"。

- 宠物模型上有两个道具骨骼：答题纸和铅笔，只在考试动作里显示（和 0.1.1 的表情部件同一个做法）。考试期间手里拿的工具不画出来，只剩铅笔；弹吉他时同样。
- 答题时上身前倾到桌上，铅笔从下巴底下落到桌上的本子上，写一阵停一下像换行；每只中间插一段自己的小插曲：

  | 角色 | 写字节奏 | 小插曲 |
  | --- | --- | --- |
  | 吉伊 | 一般 | 卡住了：冒汗，铅笔举在半空 |
  | 小八 | 一般 | 卡住了：两滴汗，铅笔抵着下巴 |
  | 乌萨奇 | 飞快、潦草 | 从不卡壳：东张西望，在座位上左右晃 |
  | 飞鼠 | 写几笔停一下 | 东张西望，扭来扭去地歪头 |
  | 栗子馒头 | 慢 | 望着远处，张大嘴打个哈欠 |
  | 狮萨 | 稳 | 坐直，点两下头 |
  | 獭师父 | 快而有把握 | 坐直抱起双臂，头保持水平 |
  | 古本屋 | 仔细 | 凑近本子，像在推敲字句 |

- **交卷**（1 秒，不起身）：把答题纸推过桌面、翻过来扣下，身子坐起一半，点一下头。

**第二天早上看结果：** 宠物回到桌前看结果单，然后当场揭晓：通过是开心的表情，没过时吉伊哭，其余角色困惑；各自说一句（见 2.5 节的说话时刻），主人的聊天栏同时收到结果。中午还没去看的、或者桌子没了的，就地揭晓。

**谁会去考：** 跟随和自由活动的宠物都会去，坐下的不去。考试的意图比领工作牌优先，因为主人付了钱。

### 2.5 数据

- **`data/<命名空间>/pet_qualification/<证>.json`**：一种证一个文件，写等级数 `grades`、报名费 `fee`（物品和数量）、哪种牌算练习 `practice_task`、报考要做几张 `required_practice`、各级基础通过率 `base_pass`、练习和越挫越勇的加成与上限（`practice_per_slip`、`practice_cap`、`fail_bonus`、`fail_cap`）、参考书 `book` 和加成 `book_bonus`、通过率上限 `max_pass`、答卷时长 `write_ticks`、野生宠物的等级分布 `wild_grades`。0.1.2 只有 `weeding.json`，由数据生成写出，`/reload` 生效；整合包可以加新的证。
- **性格** `pet_personality/<宠物>.json` 里每种证一项：
  ```json
  "qualifications": { "chiikawa:weeding": { "aptitude": 0.7, "fail_reaction": "hurt" } }
  ```
  `aptitude` 是通过率系数，`book_bonus` 是这个角色读书额外加的，`fail_reaction` 是没考过时的表情。
- **除草报酬**：除草报酬的战利品表加几个条目，每个条目带战利品条件 `chiikawa:qualification`（"这只宠物的某种证至少是几级"），做法和原版的战利品条件一样，整合包可以改成别的奖励。高级除草牌是 `pet_task` 里新加的一种牌，要求写在牌的 `requires` 里。
- **商店**：`shop_catalog` 加除草证参考书，价格 4。
- **说话**：`pet_voice` 新加两个时刻 `exam_pass`、`exam_fail`，按各角色的说话方式写，三种语言；栗子馒头没考过时不说话。

### 2.6 怎么做

- **证存在宠物身上**（`Licence`）：等级、上次考试后的练习次数、落榜次数、是否读过参考书，以及考试进行到哪一步（`ExamStage`：没有、报了名、交了卷），交了卷的连同结果一起存。
- **规则是纯函数**（`QualificationExam`）：什么时候能报名、能不能考、什么时候出结果、通过率（`PassOdds` 拆成各项，界面上的明细就是它）、野生宠物的等级。不碰实体，单元测试直接测。
- **报名**（`ExamEnrollment`）：桌子能不能收人、主人附近每只宠物的报名情况、交费报名；不知道网络和界面。交费和宠物钱包共用 `Payment`。
- **考试桌**：`ExamDeskBlock` 照着原版 `BedBlock` 写，两半各有方块实体负责画，只有桌子那一半存报名（`DeskBooking`），桌上显示哪张纸（`DeskSheet`）由报名和时间推出来，过时自动失效。网络是 `ExamDeskPayloads` 和 `ExamDeskServerPacketHandler`，界面是 `ExamDeskScreen`。
- **意图**：`take_exam`（走到椅子坐下、答卷、交卷后再坐一秒）和 `check_results`（第二天早上回到桌前看结果）。`PetExams` 每秒检查一次：错过的、桌子没了的作废并告诉主人，中午还没看的、桌子没了的就地揭晓。
- **画面**：`ExamDeskRenderer` 画桌子和椅子两个模型，只显示当前那张纸；作为物品和在手册里，桌子按 `PropAtRest` 画成空桌。宠物身上的道具骨骼由 `PropBone` 统一管，什么时候显示由 `ShownDuring` 决定；道具在手上时 `HeldItemLayer` 不画手里的物品。
- **动作**：8 只的 `exam`、`hand_in`、`read_results` 由同一个生成脚本按每只的参数写出，再在 Blockbench 里对照桌椅从几个角度检查，量过桌面、笔尖和手臂的间隙。

### 2.7 测试

- **单元测试**：数据解析与取值范围；通过率各项与上限；报名时间、截止、出结果和就地揭晓的时间；野生宠物的等级分布；战利品条件按等级判断；`Licence` 的各步转换和存档；桌子的报名与过时；交费；桌椅模型在各自方块内、高度和代码里的常数一致、每张纸的骨骼都在；8 只的坐姿和考试姿势贴在椅面上；每只考过时都有话说；手里有道具时不画物品。
- **GameTest**：报名扣一颗钻石并占下桌子；一张桌子只收一只；没练习的、坐下的报不了名；报了名的宠物坐到桌前答卷、交卷；拆桌子（拆椅子也连着桌子一起拆）这次作废；第二天早上在桌前看结果；错过考试的作废；桌子没了的、错过早上的就地揭晓；参考书每次考试前只读一本；有证的宠物除草报酬更多。

## 3. 口哨糖

### 3.1 来由

issue #1 的玩家想要一个按键或道具，一次给身边所有宠物下指令：探险时一会儿要大家一起打，一会儿只要跟着。

- **参考**：主流宠物模组不做管理面板，而是一个带模式的道具或一个按键。Doggy Talents 的哨子潜行右键选模式、右键对范围内所有狗执行；车万女仆本体也只能一只一只管。
- **为什么是口哨糖（フエラムネ）**：原作里吉伊梦见乌萨奇变成了嵌合体，早上哭着去找它，最后在涌出口哨糖的泉水边找到了正在玩的乌萨奇。它是哨子，也是吃的，吹一次吃一颗，正好是"指挥大家要有代价"。用自己的道具，不和吃东西、不和别的模组的右键冲突。

### 3.2 规则

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 模式 | 跟随、坐下、自由活动 | 记在这组糖上，物品名字显示当前模式；潜行右键切换，不吃糖 |
| 吹 | 按住右键 0.5 秒 | 原版山羊角的吹奏姿势；吹完吃掉一颗，**有没有宠物听到都吃** |
| 冷却 | 2 秒 | 防止手滑连吹 |
| 范围 | 32 格 | 同一个世界、已加载的宠物；不跨维度，叫不动没加载的（那是铃铛的事） |
| 自己的宠物 | 每只等 0 到 0.5 秒，各自错开，然后切换到当前模式 | 跟随时开心一下、说一句（"听到口哨"的说话时刻） |
| 野生宠物 | 只在跟随模式下，好奇地凑过来看 10 秒再回去 | 不会被驯服，指令不变 |
| 别人的宠物 | 不受影响 | |
| 正在考试的 | 不受影响 | 坐在考试桌前答卷的继续写 |
| 获得 | 商店 1 绿宝石买 4 颗；3 个糖合成 4 颗 | 商店的价格可以是"一份几个"，见 3.3 节 |

### 3.3 数据与代码

- **`data/<命名空间>/pet_whistle/<物品>.json`**：按物品 id 一个文件，写范围 `range`、吹多久 `blow_ticks`、冷却 `cooldown_ticks`、反应最多晚多久 `react_delay_ticks`、野生宠物好奇多久 `curious_ticks`、声音 `sound` 和音高 `pitch`。整合包可以调口哨糖怎么吹。
- **商店**：`shop_catalog` 的条目多了 `count`（默认 1），一个价格买卖几个；买的时候要放得下一整份，卖的时候要有一整份。宠物逛商店买到的也是一整份。
- **说话**：`pet_voice` 新加时刻 `whistle`，栗子馒头不说话。
- **代码**：
  - `WhistleCandyItem` 只管吹：姿势、模式、吃糖、冷却、结果提示。
  - `PetWhistle` 管谁听到、听到后做什么，不知道道具；谁听得到是纯函数 `WhistleHearing`。
  - 自己的宠物把"晚一点执行的指令"记在大脑里（`WhistleCall`），到点后调用现有的切换指令。
  - 野生宠物记下"谁在哪吹的"（`WhistleHeard`），由新意图 `answer_whistle`（只给野生宠物）走过去看。
  - 吹奏时长是服务器的数据，客户端拿不到，所以客户端的姿势用原版弓那样的长时长，由服务器吹完时结束。
- **测试**：单元测试覆盖谁听得到、模式切换、数据解析、商店的份数；GameTest 覆盖附近的跟随和坐下、远处的不受影响、没人听到也吃糖、野生的凑过来且还是野生的、考试中的不受影响、潜行切换、商店买一整份。

## 4. 动作重做（移到 0.1.2 之后）

> 这一节从 0.1.2 拿出来，0.1.2 验收后单独做；下面是当时的设计，到时再定。

之前的动作是从各处拼来的，风格不统一，而且大多是给旧模型做的。这次所有角色的动作都在 Blockbench 里统一重做，再按每个角色的性格做出区别；另外加一批闲着时会随机做的小动作。

### 4.1 现状

- 除小八外，7 个角色（吉伊、乌萨奇、狮萨、飞鼠、栗子馒头、獭师父、古本屋）的新模型手脚只有一节，但它们各自 16–22 个动画仍在驱动 `LeftForeArm`、`LeftLowerLeg`、`LeftFoot` 等模型里已经没有的骨骼。
- 旧动画靠"大腿一个角度、小腿反向弯"组合出姿势，少了一节后有的姿势会走样。0.1.1 的栗子馒头坐姿就是这样出的问题，当时只修了坐姿。
- 动画里还留着 `molang` 这种旧模型的伪骨骼；`ysm.*` 变量已在 0.1.2 写成 0（第 1 节）。
- 闲着时只有看人、走几步、发呆，没有别的动作。

### 4.2 统一的基础动作

- 8 个角色共用一套**基础动作**：待机、走、跑、坐、跳、游泳、攻击、受伤、驯服、倒下，以及已有的表情和场景动作。先在一个角色身上做好，其余角色在此基础上改。
- 每个角色再按性格调**节奏和幅度**，例如：
  - 吉伊：步子小、略显胆怯；
  - 乌萨奇：一蹦一跳、动作夸张；
  - 栗子馒头：慢悠悠；
  - 獭师父：稳重，动作利落。
- 小八的模型还是两节手脚，同样重做，让风格和大家统一。
- 删掉驱动不存在骨骼的通道，以及 `molang` 伪骨骼。

### 4.3 闲时小动作

宠物闲着时，除了看人、走几步、发呆，还会不时做一个自己的小动作。每个角色 3 个左右，按原作里的性格和习惯设计：

| 角色 | 小动作（初稿） |
| --- | --- |
| 吉伊 | 小小地跳一下；揉揉眼睛；缩起身子抖一抖 |
| 小八 | 举起双手比出拍照的样子；跟着节奏左右摇摆；挥挥手 |
| 乌萨奇 | 原地连蹦几下；突然举手大叫；转一圈 |
| 狮萨 | 认真地鞠个躬；抹一把汗；做个伸展，像开工前热身 |
| 飞鼠 | 双手捧脸摆可爱姿势；气鼓鼓地跺脚；假哭 |
| 栗子馒头 | 端杯仰头喝一口，然后满足地叹气；拍拍肚子；打个盹 |
| 獭师父 | 挥剑练一下；抱臂站定；低头擦剑 |
| 古本屋 | 低头翻书；扶一扶头上的发箍；整理一下书 |

- 小动作复用 0.1.1 的动作通道（互动场景里做动作用的就是它），不影响看人和转头。
- 做小动作时可以配一句口癖，用 0.1.1 已有的 `idle` 说话时刻，不另加。

### 4.4 数据

性格的 `idle` 里加一项 `act`，写这个角色的小动作和各自的权重，和看人、走几步、发呆一起按权重挑：

```json
"idle": {
  "act": { "weight": 2, "animations": [
    { "animation": "idle_hop", "weight": 2 },
    { "animation": "idle_rub_eyes", "weight": 1 }
  ] }
}
```

模型里没有的动画名不会报错，只是什么都不做，所以整合包可以先写上、再用资源包补动画。

### 4.5 做法

- 全部在 Blockbench 里做；每个动作都对照底板确认贴地，并用 4.6 节的测试检查。
- 按角色推进：每做完一个角色的基础动作和小动作，我把动画文件加载进你的 Blockbench 并部署测试包，你在 Blockbench 或游戏里预览，确认风格后再做下一个。
- 顺序：先做吉伊定下基础动作，再做其余 7 个。

### 4.6 守护测试

- **动画只驱动模型里有的骨骼**：新的单元测试，任何动画引用了模型里没有的骨骼就失败。重调完成后，以后模型再改骨架，动画没跟上会被立刻发现。
- **贴地**：把 0.1.1 的 `PetPosesTest` 从坐姿扩展到待机、走、跑等站在地上的动作（各取几帧），最低点离地超过 0.25 像素就失败。
- **小动作都有动画**：每个角色性格里写的小动作，它的动画文件里都要有。
- **GameTest**：闲着的宠物会做它自己的小动作。

## 5. GameTest 卡死修复

- **原因**：1.21.5 起，原版 `PlayerList.placeNewPlayer` 用一张只有 1 tick 有效期的 `UNKNOWN` 票据加载区块，再在服务器线程上原地等实体加载完。GameTest 创建模拟玩家时，如果那个区块事先没加载，票据可能先过期，服务器就永远等下去。0.1.1 移植时在 1.21.7 上碰到过一次，卡了两个多小时。
- **修法**：
  - `GameTestKit.player` 在创建模拟玩家之前，先用常驻票据把玩家要去的区块和实体加载好，再创建，最后撤掉票据。
  - 验收脚本给每个 GameTest 服务器加 15 分钟超时，超时就判失败并保留线程快照。
- 只影响开发时的验收，不影响玩家。
