## 2. 除草证

### 2.1 原作与取舍

- 原作里有好几种资格：除草资格（草むしり検定）、お酒の資格、スーパーアルバイター、驾照。考到资格报酬会提高，除草资格考过后负责的区域也会变（[キャラクターノート](https://character-note.com/archives/1370)）。
- 除草资格按级别分，级别越小越高。吉伊考了三次才过 5 级（[KAI-YOU](https://kai-you.net/article/92836)），乌萨奇早就是高级（[KAI-YOU](https://kai-you.net/article/92874)）；栗子馒头持有お酒の資格，狮萨在学。
- **不照搬原作的等级**：剧情大家都知道，照抄就没有玩头。我们要的是"考证"这件事本身：每个角色都能考，只是各有长短；等级是在游戏里一点点考出来的。
- 网上流传的"7 道四选一"考题是粉丝自编的模拟题，不采用；宠物考试也不出题，只算通过率。

### 2.2 玩家看到的

- 宠物界面多一行：`除草证：3 级`（没考过显示"无"）。
- 每隔几天是**考试日**。考试日白天，攒够条件的宠物会自己去劳动公告板考试（公告板代表管资格的鎧さん）。考试的样子见 2.4 节。
- 第二天早上公布结果：考过试的宠物去公告板看榜，当场开心或难过，主人的聊天栏同时收到提示。
- 商店卖**除草证参考书**。主人手持参考书右键自己的宠物，它就会读书备考；下一次考试通过率提高，参考书用掉。
- 手册加一页"考资格证"。

### 2.3 规则

所有数字都在数据里，下表是默认值：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 等级 | 5 级到 1 级，1 级最高 | 没证的宠物先考 5 级 |
| 初始等级 | 没有 | 驯服的、刷怪蛋出来的、复活的都不会凭空有证 |
| 野生宠物 | 按角色倾向随机 | 多数没有，少数带 5 级或 4 级，极少数更高；野生宠物不考试 |
| 考试日 | 每 7 天一次 | 按游戏内日数算，全世界统一，所有公告板同一天考 |
| 报考条件 | 上次考试后完成过至少 1 张除草牌 | |
| 基础通过率 | 5 级 40%、4 级 30%、3 级 22%、2 级 15%、1 级 8% | 考的是下一级，一次只考一级，越往上越难 |
| 练习 | 上次考试后每完成一张除草牌 +3%，最多 +30% | 只算公告板的除草牌，自己随手除草不算 |
| 读书 | 读过参考书 +25%，考完用掉 | 一次只能读一本：读过还没考的，再给参考书不收 |
| 越挫越勇 | 每落榜一次 +5%，最多 +20%，考过清零 | 屡败屡考，最后总能过 |
| 角色倾向 | 以上加总后乘以角色对这种证的系数 | 见下；最终通过率不超过 95% |

**角色倾向**（性格数据里的系数，按原作的性格来定，但不写死结局）：

| 角色 | 系数 | 依据 |
| --- | --- | --- |
| 吉伊 | 0.7 | 考试容易紧张，但肯练 |
| 小八 | 1.0 | 靠参考书稳稳考过 |
| 乌萨奇 | 1.4 | 什么都一学就会 |
| 狮萨 | 1.1 | 认真努力 |
| 飞鼠 | 0.6 | 不爱干活 |
| 栗子馒头 | 0.9 | 慢悠悠，不着急 |
| 獭师父 | 1.1 | 什么都做得好 |
| 古本屋 | 1.0 | 书多，读书加成额外 +10% |

例：吉伊考除草证 5 级，没读书、练了 5 次、落榜过 1 次，通过率 (40% + 15% + 5%) × 0.7 = 42%。

### 2.4 考试的样子

考试只有笔试，全程在劳动公告板前进行，**30 秒**，**第二天公布结果**。

**考试当天：**

| 段 | 时长 | 动作 |
| --- | --- | --- |
| 坐下 | 1 秒 | 走到公告板前的座位，面向公告板坐下；答题纸出现在身前地上，铅笔出现在右手 |
| 答题 | 约 26 秒 | 上身前倾约 15°，低头约 20°；左手按住纸，右手握笔小幅来回划，写一阵停一下像换行。期间不时插进这个角色自己的小插曲 |
| 交卷 | 3 秒 | 站起来，把答题纸交到公告板上，然后离开 |

- 答题那一段的长度每只宠物随机浮动几秒，几只一起考时不会同时交卷；具体时长写在除草证的数据里。
- 答题时各角色的节奏和小插曲：

  | 角色 | 写字节奏 | 小插曲 |
  | --- | --- | --- |
  | 吉伊 | 慢 | 停下笔，抬头左右张望；偶尔全身抖一下 |
  | 小八 | 稳 | 写一阵点一下头 |
  | 乌萨奇 | 很快 | 头几秒唰唰写完，把笔一扔，剩下的时间在座位上左右晃 |
  | 狮萨 | 稳 | 坐得比别人直，几乎不停笔 |
  | 飞鼠 | 断断续续 | 写两笔就用手托着腮发呆，歪着头 |
  | 栗子馒头 | 很慢 | 偶尔停下来深呼吸，身子鼓起来再瘪回去 |
  | 獭师父 | 快而整齐 | 提前写完，抱起双臂等着 |
  | 古本屋 | 稳 | 开头先翻几下书，再开始写 |

**第二天早上看榜：**

- 前一天考过试的宠物自己走到公告板前，站在合格发表牌前看一会儿，然后当场揭晓：
  - **通过**：双手把答题纸举过头顶，原地跳一下，开心的眼睛，说一句。
  - **没过**：低头，手耷拉下来。吉伊用 0.1.1 的哭脸和眼泪，其余角色是困惑的表情，说一句。
- 同时主人的聊天栏收到结果。
- 走不到公告板的（跟着主人在远处、坐着），到中午直接在它身上揭晓，聊天栏照样提示。

**公告板上的通知：**

- **考试通知牌**：考试前一天和考试当天挂在公告板上，挂法和工作牌一样，颜色不同。
- **合格发表牌**：考试第二天换上，挂到下一次考试通知为止。
- **公告板界面**：最上面一行写"除草证考试：明天 / 今天"；下面列出在这块公告板考过的宠物和结果（如"吉伊 5 级 合格"），保留到下一个考试日。
- **前一天晚上**，主人的聊天栏会提示"明天是除草证考试"，只发给有宠物符合报考条件的主人。
- **宠物界面**：除草证等级下面一行写"下次考试：还有 3 天"，没攒够条件时写"还没完成除草牌"。
- 公告板模型在 Blockbench 里加两块牌子（考试通知、合格发表），和工作牌一样由方块实体按日子显示。

**谁会去考：**

| 指令 | 考试 | 看榜 |
| --- | --- | --- |
| 自由活动 | 考试日自己去离家最近的公告板 | 自己去 |
| 跟随 | 只在主人走到公告板 16 格内时过去考，考完回到主人身边 | 同样只在主人在公告板附近时去，否则中午直接揭晓 |
| 坐下 | 不去 | 中午直接揭晓 |

- 另外要同时满足：那天是考试日白天；上次考试后至少完成过 1 张除草牌；还没考到 1 级。
- 每块公告板前最多 4 个座位，坐满了的宠物去附近别的公告板，附近没有就等下次。
- 错过考试不会有损失：练习次数（有上限）和越挫越勇的加成都会保留。
- 不做"参加考试"的开关。

**打断与意外：**

- 考试中被打断（被攻击、被叫坐下、跟随时主人走远）：这次考试作废，不出结果，不扣练习次数。
- 考完到看榜之间宠物倒下：结果跟着玩偶保存，复活后第二天早上照常看榜。
- 通过与否在交卷时就算好，存在宠物身上，第二天才揭晓；第二天的状态不会改变结果。

**道具**：答题纸和铅笔做成宠物模型上的两个小骨骼，平时隐藏，只在考试动作里显示（和 0.1.1 的表情部件同一个做法），不占手上的工具位。

**除草证的作用：**

- 等级越高，除草报酬越多：每升一级多 1 个绿宝石，1 级比没证多 5 个。
- **高级除草牌**：公告板升到 2 级才会贴（和讨伐牌一样）；只有除草证 3 级以上的宠物能领；工作量是普通除草牌的两倍（16–32 棵），报酬是普通的 2.5 倍，同样受等级加成。

### 2.5 数据

- **`data/<命名空间>/pet_qualification/<证>.json`**：一种证一个文件，写等级数、考试日间隔、报考条件（算哪种活）、各级基础通过率、练习和越挫越勇的加成与上限、参考书是哪个物品和加成、野生宠物的等级分布。0.1.2 只有 `weeding.json`，由数据生成写出，`/reload` 生效；整合包可以加新的证。
- **性格** `pet_personality/<宠物>.json` 新加每种证的系数：
  ```json
  "qualifications": { "chiikawa:weeding": 0.7 }
  ```
- **除草报酬**：除草报酬的战利品表加几个条目，每个条目带新的战利品条件 `chiikawa:qualification`（"这只宠物的某种证至少是几级"），做法和原版的战利品条件一样，整合包可以改成别的奖励。高级除草牌是 `pet_task` 里新加的一种牌，要求写在牌的数据里。
- **商店**：`shop_catalog` 加除草证参考书，价格 4。
- **说话**：`pet_voice` 新加两个时刻 `exam_pass`、`exam_fail`，按各角色的说话方式写，三种语言。

### 2.6 怎么做

- **等级存在宠物身上**：每种证存等级、上次考试后的练习次数、落榜次数、是否读过参考书，以及交卷时算好、等第二天揭晓的结果。
- **考试是一个新意图 `take_exam`**：
  - 属于 WORK 类，允许的指令和领牌一样（跟随、自由活动）。
  - 只在某种证的考试日白天、满足报考条件、附近有公告板时可以开始。
  - 分数比领牌略高，考试日优先去考试；同一天考过就不再去。
  - 行为是走到公告板前的座位坐下答题 30 秒，交卷后离开；结果存在宠物身上。
- **看榜是另一个意图 `check_results`**：考试第二天早上，有待揭晓结果的宠物去公告板看榜并揭晓；到中午还没看到的，直接在它身上揭晓。
- **公告板**：方块实体按日子显示考试通知牌和合格发表牌，记录在这块公告板考过的宠物和结果，给公告板界面显示；座位最多 4 个，沿用 0.1.1 互动里预约位置的做法。
- **出结果**：通过率算法放在一个纯函数里（`QualificationExam`），不碰实体，方便单元测试。
- **战利品条件**：`QualificationCondition` 读 `THIS_ENTITY` 的等级。除草报酬本来就把宠物作为 `THIS_ENTITY` 传进战利品表，所以不用改发报酬的代码。

### 2.7 测试

- **单元测试**：数据解析与取值范围；通过率计算（基础、练习、读书、越挫越勇、角色系数、上限）；野生宠物的等级分布；战利品条件按等级判断。
- **GameTest**：
  - 考试日，满足条件的宠物会去公告板坐下考试，交卷后结果存在宠物身上，当天不揭晓；
  - 第二天早上它会去公告板看榜并揭晓；走不到的到中午直接揭晓；
  - 跟随的宠物只在主人靠近公告板时去考；考试中被打断，这次作废；
  - 座位坐满时，多出来的宠物不会挤在同一块公告板前；
  - 通过率设为 1 时一定升级，设为 0 时一定不升级，落榜次数加一；
  - 读过参考书，考完后参考书的标记被清掉；
  - 除草证升级后，同一张除草牌拿到的报酬变多；没到 3 级的宠物不会领高级除草牌；
  - 不是考试日，或者没满足报考条件，宠物不会去考试。

## 3. 动作重做

之前的动作是从各处拼来的，风格不统一，而且大多是给旧模型做的。这次所有角色的动作都在 Blockbench 里统一重做，再按每个角色的性格做出区别；另外加一批闲着时会随机做的小动作。

### 3.1 现状

- 除小八外，7 个角色（吉伊、乌萨奇、狮萨、飞鼠、栗子馒头、獭师父、古本屋）的新模型手脚只有一节，但它们各自 16–22 个动画仍在驱动 `LeftForeArm`、`LeftLowerLeg`、`LeftFoot` 等模型里已经没有的骨骼。
- 旧动画靠"大腿一个角度、小腿反向弯"组合出姿势，少了一节后有的姿势会走样。0.1.1 的栗子馒头坐姿就是这样出的问题，当时只修了坐姿。
- 动画里还留着 `molang` 这种旧模型的伪骨骼和 `ysm.*` 变量，启动时会报 53 条警告。
- 闲着时只有看人、走几步、发呆，没有别的动作。

### 3.2 统一的基础动作

- 8 个角色共用一套**基础动作**：待机、走、跑、坐、跳、游泳、攻击、受伤、驯服、倒下，以及已有的表情和场景动作。先在一个角色身上做好，其余角色在此基础上改。
- 每个角色再按性格调**节奏和幅度**，例如：
  - 吉伊：步子小、略显胆怯；
  - 乌萨奇：一蹦一跳、动作夸张；
  - 栗子馒头：慢悠悠；
  - 獭师父：稳重，动作利落。
- 小八的模型还是两节手脚，同样重做，让风格和大家统一。
- 删掉驱动不存在骨骼的通道，以及 `molang` 伪骨骼和 `ysm.*` 表达式。

### 3.3 闲时小动作

宠物闲着时，除了看人、走几步、发呆，还会不时做一个自己的小动作。每个角色 3 个左右，按原作里的性格和习惯设计：

| 角色 | 小动作（初稿） |
| --- | --- |
| 吉伊 | 小小地跳一下；揉揉眼睛；缩起身子抖一抖 |
| 小八 | 举起双手比出拍照的样子；跟着节奏左右摇摆；挥挥手 |
| 乌萨奇 | 原地连蹦几下；突然举手大叫；转一圈 |
| 狮萨 | 认真地鞠个躬；抹一把汗；做个伸展，像开工前热身 |
| 飞鼠 | 双手捧脸摆可爱姿势；气鼓鼓地跺脚；假哭 |
| 栗子馒头 | 端杯仰头喝一口，然后满足地叹气；拍拍肚子；打个盹 |
| 獭师父 | 挥剑练一下；抱臂站定；低头擦剑 |
| 古本屋 | 低头翻书；扶一扶头上的发箍；整理一下书 |

- 小动作复用 0.1.1 的动作通道（互动场景里做动作用的就是它），不影响看人和转头。
- 做小动作时可以配一句口癖，用 0.1.1 已有的 `idle` 说话时刻，不另加。

### 3.4 数据

性格的 `idle` 里加一项 `act`，写这个角色的小动作和各自的权重，和看人、走几步、发呆一起按权重挑：

```json
"idle": {
  "act": { "weight": 2, "animations": [
    { "animation": "idle_hop", "weight": 2 },
    { "animation": "idle_rub_eyes", "weight": 1 }
  ] }
}
```

模型里没有的动画名不会报错，只是什么都不做，所以整合包可以先写上、再用资源包补动画。

### 3.5 做法

- 全部在 Blockbench 里做；每个动作都对照底板确认贴地，并用 3.6 节的测试检查。
- 按角色推进：每做完一个角色的基础动作和小动作，我把动画文件加载进你的 Blockbench 并部署测试包，你在 Blockbench 或游戏里预览，确认风格后再做下一个。
- 顺序：先做吉伊定下基础动作，再做其余 7 个。

### 3.6 守护测试

- **动画只驱动模型里有的骨骼**：新的单元测试，任何动画引用了模型里没有的骨骼就失败。重调完成后，以后模型再改骨架，动画没跟上会被立刻发现。
- **贴地**：把 0.1.1 的 `PetPosesTest` 从坐姿扩展到待机、走、跑等站在地上的动作（各取几帧），最低点离地超过 0.25 像素就失败。
- **小动作都有动画**：每个角色性格里写的小动作，它的动画文件里都要有。
- **GameTest**：闲着的宠物会做它自己的小动作。

## 4. GameTest 卡死修复

- **原因**：1.21.5 起，原版 `PlayerList.placeNewPlayer` 用一张只有 1 tick 有效期的 `UNKNOWN` 票据加载区块，再在服务器线程上原地等实体加载完。GameTest 创建模拟玩家时，如果那个区块事先没加载，票据可能先过期，服务器就永远等下去。0.1.1 移植时在 1.21.7 上碰到过一次，卡了两个多小时。
- **修法**：
  - `GameTestKit.player` 在创建模拟玩家之前，先用常驻票据把玩家要去的区块和实体加载好，再创建，最后撤掉票据。
  - 验收脚本给每个 GameTest 服务器加 15 分钟超时，超时就判失败并保留线程快照。
- 只影响开发时的验收，不影响玩家。

## 6. 已定的问题

1. **等级**：5 级到 1 级，1 级最高；一开始都没有证，野生宠物随机；每个角色都能考，通过率靠角色倾向、练习、读书、越挫越勇。
2. **只考笔试**，30 秒，第二天看榜公布结果；不做实技。
3. **考试日**：每 7 天一次，全世界统一。
4. **不做**"参加考试"的开关，也不让主人主动叫宠物去考；跟随中的宠物由主人带到公告板附近才考。
5. **报酬**：每升一级多 1 个绿宝石；高级除草牌要公告板 2 级、除草证 3 级以上。
6. **通知**：公告板上的考试通知牌和合格发表牌、公告板界面的合格名单、宠物界面的"下次考试"、前一晚的聊天提示。
7. **动作**：闲时小动作按第 3.3 节的初稿做；先做吉伊定风格，你在 Blockbench 或游戏里看过再做其余 7 个。
8. **饮酒证**：放到之后的版本。
