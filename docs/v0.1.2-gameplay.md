# 0.1.2 玩法：除草证

> 这里只写 0.1.2 新增、玩家看得到的部分；打工、商店、公告板见 [v0.1.0-gameplay.md](v0.1.0-gameplay.md)，口癖和伙伴之间见 [v0.1.1-gameplay.md](v0.1.1-gameplay.md)。怎么做的见 [v0.1.2-design.md](v0.1.2-design.md)。

宠物可以考除草证（草むしり検定）了。主人在考试桌给它报名、交一颗钻石，它坐到桌前答卷，第二天早上看结果。考到的级别越高，除草挣得越多。

另外多了口哨糖，吹一颗，附近的宠物一起听你的；音乐盒也能选播放模式了。

---

## 1. 除草证

- **等级：** 5 级到 1 级，1 级最高。宠物一开始都没有证，先考 5 级，一次只考下一级。野生宠物多数没有证，少数带着 5 级或 4 级，极少数更高。
- **有什么用：**
  - 每升一级，每张除草牌多 1 个绿宝石，1 级比没证多 5 个。
  - 公告板升到 2 级后会贴**高级除草牌**，只有除草证 3 级以上的宠物能领：草是普通的两倍（16–32 棵），报酬是普通的 2.5 倍，同样按等级加。
- **在哪看：** 宠物界面有一行除草证，写着它几级，下面写现在怎么样：还要多练练、可以去考试桌报名、今天在考、明天早上出结果。

---

## 2. 报名

- **考试桌：** 一张课桌连着后面的椅子，占两格，像床一样一起放、一起拆，拆下来是一张考试桌。配方：上排 3 个木台阶，下排木棍、纸、木棍。
- **右键考试桌**（桌子或椅子都行）打开报名界面：你附近的宠物各占一行，写着它要考几级、通过率多少；鼠标停在通过率上能看到每一项加了多少。不能去的写着原因。
- 选一只，按**报名**，从你身上扣 1 颗钻石。
- **限制：**
  - 只在白天 7:00 到 15:00 能报名。
  - 一张桌子一次考一只；椅子上方被挡住时不能报名。
  - 只能给自己的宠物报名。坐下的不去；离得太远的不去，范围和它平时领工作牌一样。
  - 上次考试后要至少做完 1 张除草牌；已经 1 级的、已经报了名或在等结果的不能再报。
- **钻石不退：** 17:00 前没坐下答卷就算错过；考试中拆掉桌子，这次也作废。两种情况钻石都不退，但它练习和读书攒下的加成都还在。

---

## 3. 考试

- 报了名的宠物自己走到椅子上坐下，写大约 26 秒，交卷，主人的聊天栏会提示"交卷了，结果明天早上出"。
- 桌上放着它的答题纸，手里拿着铅笔；考试时手里的工具收起来不画，只剩铅笔。
- 每只写字的样子按原作的性格：

| 角色 | 怎么写 | 中间 |
| --- | --- | --- |
| 吉伊 | 一笔一笔地写 | 卡住了，冒着汗，铅笔举在半空 |
| 小八 | 一笔一笔地写 | 卡住了，两滴汗，铅笔抵着下巴 |
| 乌萨奇 | 唰唰地乱写 | 从不卡壳，东张西望，在座位上晃来晃去 |
| 飞鼠 | 写几笔停一下 | 东张西望，扭来扭去地歪头 |
| 栗子馒头 | 慢慢写 | 望着远处，张大嘴打个哈欠 |
| 狮萨 | 稳稳地写 | 坐直，点两下头 |
| 獭师父 | 写得又快又稳 | 坐直抱起双臂 |
| 古本屋 | 仔细地边看边写 | 凑近本子推敲字句 |

- 交卷时把答题纸推过桌面、翻过来扣下，点一下头。

## 4. 看结果

- 第二天早上，宠物回到考试桌前看结果单：通过是红圈，没过是红叉。
- 当场揭晓：通过的开心，没过的吉伊会哭，其他角色一脸困惑。各自说一句，主人的聊天栏同时收到结果。

## 5. 通过率

| 项 | 默认 |
| --- | --- |
| 基础 | 5 级 40%、4 级 30%、3 级 22%、2 级 15%、1 级 8% |
| 练习 | 上次考试后每做完一张公告板的除草牌 +3%，最多 +30%；自己随手除草不算 |
| 读书 | 读过除草证参考书 +25%，考完用掉 |
| 越挫越勇 | 每落榜一次 +5%，最多 +20%，考过清零 |
| 角色 | 以上加起来再乘以角色的系数：飞鼠 0.6、吉伊 0.7、小八 0.8、栗子馒头 0.9、古本屋 1.0、狮萨和獭师父 1.1、乌萨奇 1.4 |
| 上限 | 95% |

- **参考书：** 商店卖，4 个绿宝石。手持参考书右键自己的宠物，它会读书备考；读过还没考的，再给不收。古本屋书多，读书额外 +10%。
- 例：吉伊考 5 级，没读书、练了 5 次、落榜过 1 次，通过率 (40% + 15% + 5%) × 0.7 = 42%。

## 6. 口哨糖

原作里吉伊在涌出口哨糖（フエラムネ）的泉水边找到了乌萨奇。口哨糖是一颗中间有孔的糖，能吹响，吹完就吃掉。

- **获得：** 商店 1 个绿宝石买 4 颗；3 个糖合成 4 颗。
- **潜行右键：** 切换模式：跟随 → 坐下 → 自由活动。物品名字上写着当前模式，切换不吃糖。
- **按住右键：** 举到嘴边吹，吃掉一颗，附近 32 格内你的宠物都照当前模式做：
  - **跟随**：跑过来跟着你，拿武器的会自己上去打；野生宠物也会好奇地凑过来看一会儿，但不会因此被驯服。
  - **坐下**：原地坐下等你。
  - **自由活动**：各自散开，回去干自己的事。
- 吹一次就吃一颗，附近没有宠物也一样。别人的宠物、正在考试桌前答卷的宠物不受影响。
- 不跨维度，也叫不动没加载的宠物；把走丢的宠物找回来还是用铃铛。

宠物听到"跟随"时会回一句：

| 角色 | 台词 |
| --- | --- |
| 吉伊 | 「ワッ…!」 |
| 小八 | 「呼んだ〜？」 |
| 乌萨奇 | 「ヤハーッ!!」 |
| 飞鼠 | 「よこせッ」 |
| 栗子馒头 | 不说话 |
| 獭师父 | 「…行くか」 |
| 狮萨 | 「はーい!」 |
| 古本屋 | 「はい…」 |

## 7. 音乐盒的播放模式

音乐盒界面多了一个按钮，点一下换一种播放模式，拿着这个音乐盒的宠物就照着弹。

| 模式 | 弹完一首以后 |
| --- | --- |
| 单次播放 | 停下。和以前一样，领了街头演奏牌时会一直弹到牌做完 |
| 列表循环 | 接着弹列表里的下一首，弹到最后一首再从头开始 |
| 随机播放 | 随机挑一首接着弹，不会紧接着重复刚才那首 |
| 单曲循环 | 再弹一遍选中的那首 |

后面三种模式下，宠物只要没别的事就会一直弹下去，可以当整个院子的背景音乐。换歌或者换模式都从选中的那首重新开始。服务器同时能放的音乐流有上限，满了的时候，宠物会等一会儿再试。

## 10. 整合包能改什么

和之前一样，能调的都在数据包里，默认值由数据生成写出，两个 loader 读同一份。

| 内容 | 路径 | 能改什么 | 何时生效 |
| --- | --- | --- | --- |
| 证 | `data/<命名空间>/pet_qualification/<证>.json` | 等级数 `grades`；报名费 `fee`（`item`、`count`）；哪种牌算练习 `practice_task`、报考要做几张 `required_practice`；各级基础通过率 `base_pass`；练习、越挫越勇的加成和上限（`practice_per_slip`、`practice_cap`、`fail_bonus`、`fail_cap`）；参考书 `book` 和加成 `book_bonus`；通过率上限 `max_pass`；答卷多少 tick `write_ticks`；野生宠物各级的权重 `wild_grades`（从"没有"开始） | `/reload` |
| 角色倾向 | `data/<命名空间>/pet_personality/<宠物>.json` 里的 `qualifications` | 每种证一项：通过率系数 `aptitude`、读书额外加成 `book_bonus`、没考过时的表情 `fail_reaction`（`happy`、`hurt`、`confused`、`revive`） | `/reload` |
| 有证的报酬 | 除草牌的战利品表 `data/<命名空间>/loot_table/pet_task/weeding.json` | 条目可以带条件 `chiikawa:qualification`（这只宠物某种证至少几级），按等级给别的奖励 | `/reload` |
| 牌对证的要求 | `data/<命名空间>/pet_task/<牌>.json` 里的 `requires` | 领这种牌要哪种证的几级 | `/reload` |
| 说话 | `data/<命名空间>/pet_voice/<宠物>.json` | 新的时刻 `exam_pass`、`exam_fail`、`whistle` | `/reload` |
| 口哨 | `data/<命名空间>/pet_whistle/<物品>.json`（文件 id 就是物品 id） | 范围 `range`、按住多久 `blow_ticks`、冷却 `cooldown_ticks`、宠物最多晚多久反应 `react_delay_ticks`、野生宠物好奇多久 `curious_ticks`、声音 `sound`、音高 `pitch` | `/reload` |
| 商店 | `data/<命名空间>/shop_catalog/*.json` | 条目新加 `count`：一个价格买卖几个，默认 1 | `/reload` |

例：把报名费改成 3 个绿宝石，`weeding.json` 里写

```json
"fee": { "item": "minecraft:emerald", "count": 3 }
```
