# 0.1.0 玩法：打工与绿宝石

吉伊们会自己去公告板领工作牌、干活、赚绿宝石，再用自己赚的钱买东西，也会给主人买礼物。主人可以拿走宠物的钱、给宠物零花钱、给宠物买东西。怎么对待宠物由主人决定，宠物也有一点自己的主意。

---

## 1. 核心循环

| 谁 | 钱从哪来 | 钱花在哪 |
| --- | --- | --- |
| 宠物 | 自由活动时去公告板领工作牌，完成后报酬是绿宝石，放进自己的背包 | 给自己买想要的东西、给主人买礼物 |
| 主人 | 从宠物背包里拿；和村民交易；在商店卖作物和材料 | 和村民交易；在商店买宠物用品、小窝和家具、升级公告板；给宠物买东西或给零花钱 |

同一套规则下，玩家可以有完全不同的玩法：

- **宠爱：** 不拿宠物的钱，还给零花钱。宠物攒得多，经常买礼物送你。
- **放养：** 不管不问，宠物自己打工、自己花钱，偶尔送个小礼物。
- **压榨：** 养一大群宠物去打工，赶在它们花掉之前把绿宝石全部收走。宠物没钱就不会送礼。

---

## 2. 三种状态

潜行右键宠物，在三种状态之间切换：

| 状态 | 宠物做什么 |
| --- | --- |
| 跟随 | 跟在主人身边。主人身边一小圈里有公告板、商店时，也会顺路领工作牌、买东西 |
| 坐下 | 待在原地不动 |
| 自由活动 | 以切换时的位置为家，在家附近按自己的职业干活，自己去领工作牌、买东西、给主人送礼 |

原来的"工作模式"改名为"自由活动"，旧存档里处于工作模式的宠物会直接变成自由活动。

---

## 3. 职业与工作牌

**职业决定宠物做什么，工作牌决定这份活有没有报酬。**

- 职业仍然由宠物手上的工具决定，和 0.0.9 一样。
- 没有工作牌时，宠物照常做本职工作，只是没有报酬。
- 公告板上有和它职业对应的工作牌时，宠物会去领一张，回来继续做本职工作。平时干的活自动累计进度，做够数量就拿到报酬。

### 每个职业能领的工作牌

| 职业 | 工具 | 工作牌 | 进度怎么算 |
| --- | --- | --- | --- |
| 农夫 | 锄头 | 除草 | 收割作物、拔草、采蘑菇的数量 |
| 剑士 | 剑 | 讨伐 | 击败敌对生物的数量 |
| 弓手 | 弓 | 讨伐 | 击败敌对生物的数量 |
| 乐手（只有小八） | 音乐盒 | 街头演奏 | 演奏的时长 |
| 无职业 | 无 | 不领 | 无 |

### 领牌、干活、到账

- **领牌：** 公告板在宠物当前状态允许的范围内、还有对口的工作牌时，宠物会走过去领一张。有主人的宠物优先，野生的只领剩下的。
- **挂在身上：** 领了牌的宠物身上会挂一块小木牌，一眼就能看出谁在打工。打开背包能看到当前任务和进度。
- **一次一张：** 一只宠物同一时间只领一张。已经领下的牌不会因为公告板第二天刷新而作废。
- **不用在公告板附近干活：** 公告板只是领牌的地方，在哪里完成都算数。
- **完成后自动到账：** 完成的那一刻，小木牌消失，报酬直接进入背包，冒出绿宝石闪光的粒子特效，宠物做出开心的动作和语音。当天还有对口的牌，它会再去领下一张。
- **讨伐有风险：** 讨伐报酬最高。宠物在讨伐中倒下，这张牌就算失败，没有报酬；宠物照常掉落玩偶，可以放到蛋糕上复活。
- **报酬：** 以绿宝石为主，偶尔附带一点小物品。

---

## 4. 公告板

- **労働掲示板**是玩家合成、放置的方块，所有玩家的宠物都能用，不属于任何人。
- 每个 Minecraft 日出，公告板刷新当天的工作牌。
- 同一块公告板同一天刷出的工作牌，所有玩家看到的都一样。每张牌只能被一只宠物领走，先到先得。
- 右键公告板可以查看当天有哪些牌、哪些已经被领走、被谁家的宠物领走。
- 公告板附近偶尔会有野生的吉伊路过，凑过来看一看。

---

## 5. 野生的吉伊

- **生成时自带工具：** 野生吉伊生成时，会按角色倾向拿到一件基础工具，并处于自由活动状态。

| 角色 | 可能拿到的工具 |
| --- | --- |
| 吉伊 | 锄头为主，偶尔拿自己的武器 |
| 小八 | 锄头或自己的武器 |
| 乌萨奇 | 自己的武器为主 |
| 拉库 | 剑，大概率 |
| 狮萨 | 锄头 |
| 栗子馒头 | 锄头，或者空手 |
| 摩门加 | 大多空手 |
| 古本屋 | 空手 |

- **只给基础工具：** 木制、石制工具或模组的角色武器，不会生成弓和音乐盒。
- **不破坏玩家的东西：** 野生农夫只拔野外的草，不收割玩家种的作物；野生剑士只讨伐敌对生物。
- **也会打工攒钱：** 野生的会领公告板上剩下的工作牌，赚的绿宝石放在自己背包里。
- **驯服后：** 自动切到跟随状态，方便带回家。工具和它攒的绿宝石都跟着它，仍然是它的东西，主人想拿随时可以拿。
- **被打倒时：** 身上的东西照常保存在玩偶里，不会掉出来。

---

## 6. 绿宝石怎么流动

| 行为 | 规则 |
| --- | --- |
| 主人拿钱 | 随时打开宠物背包拿走，没有任何惩罚 |
| 主人给钱 | 手持绿宝石右键宠物，或者直接放进它的背包，宠物会开心 |
| 宠物花钱 | 自己决定什么时候花、买什么，只花自己背包里的绿宝石 |
| 宠物买东西 | 攒到够买想要的东西时，自己走到范围内的商店去买 |
| 宠物送礼 | 用自己的钱买礼物，跑回主人身边递过去。钱越多，送得越多 |
| 主人送东西 | 把东西递给宠物，宠物会开心并真的用上：吃掉食物、装备工具、戴上用品。送的是它喜欢的东西，反应会更明显 |

---

## 7. 商店

- 玩家放置的方块，按绿宝石买卖，宠物和主人都能用。
- **卖：** 食物、礼物类小物、宠物用品、小窝和家具、公告板升级。
- **收：** 作物、原版基础材料。
- 不卖钻石、下界合金这类会跳过原版进度的东西。

---

## 8. 每个角色的性格

宠物自己买东西、给主人挑礼物时，会按性格偏好来选；性格也会影响它有多想干活、多随性：

| 角色 | 喜欢买的东西 | 性格表现 |
| --- | --- | --- |
| 吉伊 | 零食 | 认真干活 |
| 小八 | 做饭材料、相机相关的小物 | 乐观，常去街头演奏 |
| 乌萨奇 | 什么都乱买 | 非常随性 |
| 狮萨 | さんぴん茶一类的饮品 | 勤快 |
| 摩门加 | 可爱的小东西 | 不太想干活 |
| 栗子馒头 | 下酒小菜，不含酒 | 悠闲 |
| 拉库 | 甜食，比如草莓芭菲 | 最爱讨伐 |
| 古本屋 | 书 | 安静 |

---

## 9. 宠物用品

用原版工作台合成，或者在商店购买：

- **小熊挎包：** 给宠物戴上后扩充背包，会显示在宠物身上。
- **简单料理：** 喂给宠物，一段时间内干活更快。
- **名字牌：** 给宠物起名字。
- **宠物铃铛：**把自己的宠物叫回身边，详见第 11 节。

---

## 10. 公告板升级

主人花绿宝石升级公告板：

- 每升一级，每天多一张工作牌（3 / 4 / 5）。
- 解锁报酬更高的工作牌。讨伐牌需要升到二级才会出现。
- 价钱：二级 16 颗绿宝石，三级 32 颗。升级不会换掉当天已经贴出来的牌。

---

## 11. 跟随与召回

- **跟随更可靠：** 跟随状态的宠物，即使待在别人附近那种"只加载不运算"的区块里，主人走远后也会被传送过来。
- **宠物铃铛：**右键一响，你的宠物都回到身边；未加载区块里的会被叫醒，别的维度也听得见。叫不到的会告诉你是哪一只。响过一次要等半分钟，不消耗。

---

## 12. 多人游戏

- 每只宠物只属于一个主人。其他玩家不能打开它的背包，也不能叫走它。
- 公告板和商店是公共的，所有玩家和他们的宠物都能使用。
- 宠物赚到的绿宝石只进自己的背包，宠物送礼只送给自己的主人。
