# 文案规范

模组里给玩家看的所有文字（界面、提示、消息、手册、物品说明）都按这份写。角色台词（`voice.*`）按原作口吻，不受这里的句式约束，只守术语表。

## 原则

1. **像人说话。** 写的是一个人站在旁边会怎么告诉你，不是程序的状态码。“攻击冷却中”“属于世界”“可存放的容器”这类说法都不要。
2. **短。** 一句能说完不用两句；界面上的标签能用两三个字不用五个字。说明放到鼠标悬停提示里，不挤在界面上。
3. **一件事一个叫法。** 同一个东西在界面、提示、手册、网站里叫法一样，见术语表。
4. **对玩家说“你”。** 界面和消息是说给主人听的，称“你”，不称“主人”。宠物用“它”，不分性别。
5. **说做什么，不说怎么实现。** “对宠物右键，让它读一读”，不是“手持右键自己的宠物”。

## 格式

- 中文标点用全角：，。：；（）！？；省略号用“……”。
- 中文和占位符、数字之间不加空格：`叫回了%s只宠物`、`%s级`、`10格`。英文单词和中文之间也不加空格。
- 不在句尾加句号的情况：按钮、标签、状态（如“拔草”“已领”）。完整句子的提示和消息要加，或者整条都不加，同一类保持一致。
- 冒号后面跟数值：`零花钱：%s`、`职业：%s`。

## 术语表

| 用这个 | 不用 |
|---|---|
| 宠物 | 小伙伴、小家伙（手册、提示、消息里都叫宠物） |
| 你 | 主人（界面和消息里） |
| 工作牌 | 任务、牌子 |
| 劳动公告板（物品名），句子里可简称公告板 | 公告栏、任务板 |
| 讨伐 | 清怪、打怪 |
| 跟随 / 坐下 / 自由活动 | 待命、原地、自由行动 |
| 自动拾取 | 捡东西、捡地上的东西 |
| 零花钱 | 钱、绿宝石（指宠物的钱时） |
| 背包 | 包、口袋（指宠物的格子时） |
| 考试 / 报名 / 考过了 / 没考过 | 落榜、合格（结果用口语） |

## 各类文字怎么写

- **宠物在做什么**（`intent.*`，对话气泡和提示里显示）：动词短语，不带“在”“正在”，如“拔草”“去领工作牌”“跟着你”。
- **为什么没在做**（`intent.chiikawa.fail.*`）：从宠物的处境说原因，如“附近没有野草”“背包里没有胶卷”“天还没黑”。
- **物品说明**（`tooltip.*`）：先说用来做什么，再说怎么用，最多两句。
- **消息**（`message.*`）：一件事发生了，用陈述句，如“小八考过了除草证4级！”。
- **手册**（`manual.*`）：一段讲一件事，从玩家要做的第一步说起。
