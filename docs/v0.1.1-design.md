# 0.1.1 设计：口癖、互动与模型统一

> 基于 1.21.1 分支当前代码（提交 592a0554，已合入 faces 分支的四只新模型）。
> 原作依据见 [chiikawa-ip-research.md](chiikawa-ip-research.md)。

---

## 1. 目标与范围

**目标：** 让宠物更像原作里的它们——会说自己的口癖、会有表情、彼此之间有来往；八个角色的模型和武器统一到新风格。

**本版要做**

1. 口癖：宠物在对应时刻头顶冒出对话气泡，说原作口癖，同时张嘴。
2. 表情：八个角色有同一套表情动画（开心、哭、困惑、说话），现有的表情反应真正播出来。
3. 角色互动：几组原作里的来往，两只宠物一起演。
4. 古本屋和乌萨奇按新风格重做。
5. 原作武器建模：吉伊和小八的さすまた、乌萨奇的討伐棒，新增獭师父的剑。

**不在范围内**

- 讨伐排行、草むしり検定、報酬袋、原作食物、擬態型与キメラ、労働の鎧さん、Boss。
- 披风和尾巴的物理摆动（已取消）。
- 语音：口癖只出文字气泡，不加新的音频。

## 2. 现状

- **气泡：** 只有打工手册里有对话气泡（`ManualScene`，界面里画）。游戏世界里只有准星指着宠物时的头顶状态标签（`WorldSurface`）。
- **张嘴：** 八个角色都有 `open_mouth1`、`open_mouth2` 动画，渲染器也会在它们播放时显示 `Mouth3`，但游戏里没有任何地方触发它们。
- **表情反应：** `PetReaction` 有开心、受伤、困惑、复活四种，服务端在拿到工钱、受伤、被喂食等时刻触发。它们要找的动画（`happy`、`hurt`、`confused`、`revive`）八个角色基本都没有，只有乌萨奇、小八、古本屋有 `scratch_head`，所以这些反应大多是静默的。
- **说话显示 `Mouth3`：** 吉伊、飞鼠、栗子馒头、獭师父、狮萨平时闭着嘴，渲染器只在张嘴动画播放时显示 `Mouth3`。乌萨奇的渲染器让 `Mouth3` 一直藏着，小八只在弹吉他时显示它，所以它们平时也是闭着嘴。
- **武器：** 三把"讨伐棒"是 Java 方块模型格式的一根细棍，吉伊、小八、乌萨奇各一把，都是石剑档的剑，在剑士工具标签里。獭师父没有武器。
- **古本屋：** 7 月加入时的模型，用的是小八的骨架和动画，之后只加过包的挂点；渲染器让 `Mouth3` 一直藏着，所以平时是闭嘴的 ω。

## 3. 口癖

### 3.1 玩家看到的

- 宠物在特定时刻头顶冒出一个对话气泡，写着它的口癖，同时播放张嘴动画。气泡停留约 3 秒后淡出。
- 附近的玩家都看得见（16 格内），和宠物是谁的无关；F1 隐藏界面时一起隐藏。头顶状态标签不同：它说的是宠物在做什么、做到哪了，是主人自己的事，只有主人准星指着时才出现。
- 准星指着它时，状态标签照常显示；气泡在标签上方，两者不重叠。
- 同一只宠物说完一句后有冷却，不会连续刷屏；附近宠物很多时，同一时刻最多几只在说话。

### 3.2 什么时候说

| 时刻 | 已有的触发点 |
| --- | --- |
| 被驯服 | 驯服成功 |
| 受伤 | 受到伤害（和"哭"表情一起） |
| 开始讨伐 | 进入战斗意图 |
| 拿到工钱 | 工作牌完成到账 |
| 买到东西、当场吃掉 | 商店购物 |
| 送礼 | 把礼物交给主人 |
| 复活 | 玩偶放上蛋糕 |
| 闲着 | 闲逛时低概率随机 |
| 互动 | 见第 5 节 |

### 3.3 说什么（初稿，按原作）

| 角色 | 口癖示例 |
| --- | --- |
| 吉伊 | 「ヤダッ!!」「ンショ…」「ワァ…」、讨伐时「ヤーッ!!!」、受伤时哭 |
| 小八 | 「なんとかなれーッ!!」「ってコト!?」「泣いちゃった!!」 |
| 乌萨奇 | 「ウラ」「ヤハ」「プルルル」「ハァ？」 |
| 狮萨 | 礼貌的招呼，冲绳梗（さんぴん茶） |
| 飞鼠 | 「褒めろ」「慰めろ」「ついにやったゾ!!」 |
| 栗子馒头 | 吃喝后「ハーッ…」 |
| 獭师父 | 简短的前辈口吻 |
| 古本屋 | カニ挨拶 |

口癖按各语言翻译：日文用原作台词，中文和英文各自译成当地粉丝熟悉的说法。

### 3.4 数据

每个角色说什么、在什么时刻说、概率和冷却，都放在数据包里，由数据生成写出默认值，两个加载器读同一份：

`data/<命名空间>/pet_voice/<角色>.json`

```json
{
  "lines": {
    "hurt":   [{ "text": "voice.chiikawa.chiikawa.hurt.1", "weight": 1 }],
    "hunt":   [{ "text": "voice.chiikawa.chiikawa.hunt.1", "weight": 1 }],
    "idle":   [{ "text": "voice.chiikawa.chiikawa.idle.1", "weight": 2 }]
  },
  "chance": { "idle": 0.001 },
  "cooldown_ticks": 200,
  "crowd_limit": 3
}
```

- `text` 是翻译键，文字写在语言数据里。
- 没写某个时刻，这个角色那时就不说话。
- `chance` 没写的时刻都是 1；闲着（`idle`）是每 tick 的概率，和原版环境音一样按 tick 掷。
- `crowd_limit`：16 格内已经有这么多只在说话时，这只就先不说。

### 3.5 同步

- 服务端决定说哪一句，保证所有玩家看到的一样。
- 通过一个服务端到客户端的包（宠物实体 id + 翻译键）发给追踪这只宠物的玩家，客户端收到后开始显示气泡，并播放 `open_mouth1` 或 `open_mouth2`（按台词固定选一个，大家看到的一样）。张嘴放在反应层之上单独的 `talk` 层：同一时刻触发的表情（开心、哭）晚一步到客户端，放在同一层会把张嘴顶掉；`talk` 层只动嘴，表情的其余部分照常。
- 气泡的绘制复用头顶标签的世界内绘制（`WorldSurface`），样式和打工手册里的气泡一致。

## 4. 表情

### 4.1 统一的一套表情动画

八个角色都要有下面这些动画，按各自的脸来做（脸部零件沿用各自原来的方块）：

| 动画 | 用在 | 脸上发生什么 |
| --- | --- | --- |
| `blink` | 一直循环 | 眨眼（已有） |
| `open_mouth1`、`open_mouth2` | 说话 | 张嘴，显示 `Mouth3`（已有） |
| `happy` | 开心反应 | 眼睛弯成 ^ ^，身体轻轻一跳 |
| `hurt` | 受伤反应 | 哭脸：眼泪，嘴角向下 |
| `confused` | 困惑反应 | 挠头或歪头，冒汗 |
| `revive` | 复活 | 可以和 `happy` 共用 |

- 表情需要的新零件（眼泪、弯眼、汗）做成脸上的骨骼，平时隐藏，由动画控制显示。
- `FaceAnimationsTest` 改为检查八个角色都有这一整套。

### 4.2 渲染器

- 八个角色统一成"说话时才显示 `Mouth3`"，规则留在各自的渲染器里：乌萨奇从一直藏着改成说话时显示，小八改成弹吉他或说话时显示。

## 5. 角色互动

### 5.1 玩家看到的

两只宠物离得近时，偶尔会按原作的关系一起演一小段：一只走向另一只，两只面对面，各自播动画、冒气泡，演完各走各的。

### 5.2 初版几组（按原作）

| 互动 | 发起 | 对象 | 过程 |
| --- | --- | --- | --- |
| 缠人 | 飞鼠 | 吉伊优先，其次任何人 | 飞鼠凑上去扒住头，说「褒めろ」；对方哭脸，说「ヤダッ!!」 |
| 请客 | 獭师父 | 吉伊、小八 | 獭师父从背包里拿一份吃的递过去，对方当场吃掉、开心 |
| 送咖啡 | 栗子馒头 | 刚完成除草牌的宠物 | 走过去递一杯，对方开心，短时间更有干劲 |
| カニ挨拶 | 古本屋 | 飞鼠、吉伊、小八 | 两只面对面做カニ挨拶 |
| 听演奏 | 任何人 | 正在街头演奏的小八 | 走到旁边坐下听，偶尔鼓掌 |

### 5.3 在 AI 里怎么做

- 任何两只宠物之间都可以互动：不论是不是同一个主人，野生的也算。
- 新增意图类别 `SOCIAL`。许可规则和闲逛一样：坐下时不做，其他状态和野生宠物都可以。跟随时只在离主人很近时发生，由跟随的锚点拴绳自然限制。
- 每组互动是一个发起方意图，打分低于工作和讨伐、高于闲逛，所以不会耽误干活。
- 发起时向对方"预约"：对方进入配合状态，在原地转向发起方、播动画，不会被别的互动抢走；预约有超时，发起方走不过去就取消（和公告板的预约同一个思路）。
- 冷却按"这一对宠物"和"这一种互动"记，同一对不会反复演同一段。
- 会动到物品的互动（请客）走现有的背包和物品转移逻辑，在服务端校验。

### 5.4 数据

`data/<命名空间>/pet_interaction/<id>.json`：发起方和对象（实体类型或标签）、触发条件（距离、对方刚完成什么）、双方各播的动画和说的话、冷却、概率。默认几组由数据生成写出，整合包可以增删。

## 6. 古本屋和乌萨奇重做

- 和飞鼠、栗子馒头、獭师父、狮萨一样：吉伊式圆头小身子的统一造型，尽量贴近原作。
- 脸上的零件沿用原来的方块；保留カニのカチューシャ；包的挂点和带子照旧。
- 做完第 4 节那一套表情动画。

---

### 乌萨奇

- 同样换到吉伊式的圆头小身子，比吉伊大一圈，身体更丰满；头两侧超出正脸的部分往里收一些，免得脸太宽。
- 眼睛照吉伊、小八的画法（一格一个像素，上面大高光、中间深色带、下面浅色高光）；眉毛和嘴保留原来的形状，嘴是 W 加左边 V 下的一捺，线条的转折改成干净的尖角。
- 耳朵比原来短两成、宽一成，背面奶黄色；背后加白色毛球尾巴，边上带黑色炸毛。

### 其他几只的比例

- 栗子馒头、獭师父的头两侧超出正脸的部分往里收一些，正脸不动；栗子馒头的眼睛放大一点。
- 栗子馒头、獭师父、飞鼠、狮萨的身体稍微大一点，比乌萨奇小；獭师父脖子上的披风领子收进头底下。
- 狮萨的头整体缩小一点，鬃毛跟着一起缩。

## 7. 原作武器

| 物品 | 原作 | 模型 |
| --- | --- | --- |
| 吉伊的武器（`chiikawa_weapon`） | 粉色さすまた | 叉头 + 长柄，粉色 |
| 小八的武器（`hachiware_weapon`） | 水色さすまた | 同款，水色 |
| 乌萨奇的武器（`usagi_weapon`） | 討伐棒，棒尖画着自己的脸 | 棒身 + 两端喷口，棒尖有乌萨奇的脸 |
| 獭师父的剑（新增 `rakko_sword`） | 剑柄刻着脸（讨伐排行前 4 名的证明） | 剑 + 刻脸的剑柄 |

- 模型改为基岩版，在 Blockbench 里做；贴图一个像素对应一个 texel。手持时和道具一样由物品渲染画。
- 物品 id 不变，存档里已有的武器不受影响。
- 獭师父的剑：剑士工具，加入剑士工具标签；只作为獭师父的野生初始工具出现，没有合成配方，商店也不卖。
- 名字改成原作叫法，比如中文「吉伊的刺叉」、日文「ちいかわのさすまた」，顺带解决日文「討伐武器」拿不准的问题。

## 8. 实施步骤

每一步都在 1.21.1 上完成、测试通过、提交。

1. **表情底座：** 第 4 节的表情动画，先给已有新模型的五个角色做，再给乌萨奇、小八做；`FaceAnimationsTest` 扩展。
2. **古本屋重做：** 模型和整套表情。
3. **口癖：** `pet_voice` 数据与加载、服务端触发、同步包、世界内气泡、张嘴；三种语言的文字；GameTest 覆盖触发和冷却。
4. **角色互动：** `SOCIAL` 类别、预约、配合状态、`pet_interaction` 数据；先做缠人和カニ挨拶两组把框架跑通，再加其余三组；GameTest 覆盖预约、超时、坐下不互动。
5. **原作武器：** 三把重做，新增獭师父的剑，名字和配方。
6. **收尾：** 更新 `v0.1.0-gameplay.md` 相关章节（或另起 0.1.1 玩法说明），打工手册视情况加一页。
7. **移植与发版：** 和 0.1.0 一样，以 1.21.1 的提交为基准移植到另外 13 个分支，验收后版本号改为 0.1.1，14 个分支一起发。
