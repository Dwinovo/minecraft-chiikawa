# 0.1.1 玩法：口癖与伙伴之间

> 这里只写 0.1.1 新增、玩家看得到的部分；打工、商店、公告板这些见 [v0.1.0-gameplay.md](v0.1.0-gameplay.md)。怎么做的见 [v0.1.1-design.md](v0.1.1-design.md)。

宠物会说自己的口癖了，彼此之间也有了来往：两只碰到一起，偶尔会演一段原作里的小场面。

---

## 1. 口癖

- **什么时候说：** 被驯服、受伤、出发讨伐、拿到工钱、买到东西、送礼、复活、闲逛时偶尔一句，还有和别的宠物互动时（第 2 节）。说话时头顶冒出一个对话气泡，同时张嘴。
- **谁看得见：** 16 格内的玩家都看得见，不管宠物是谁家的；按 F1 和界面一起隐藏。气泡停约 3 秒后淡出，高度固定在名牌位置再往上一行，出现以后不会跳。
- **不刷屏：** 说完一句会安静一阵，默认 10 秒；獭师父、栗子馒头、古本屋话少，安静 20 秒；飞鼠从不消停，只在上一句还挂在头上时闭嘴。附近已经有 3 只在说话时，新的一只先不说。
- **头顶只有气泡：** 准星指着宠物时的状态小卡取消了，它在做什么、做到哪了，打开它的界面看。

每个角色按原作说话，不是一套台词套给所有人：

| 角色 | 怎么说话 | 例 |
| --- | --- | --- |
| 吉伊 | 几乎不说整句话，只发声；受惊、遇到讨厌的事就哭 | 「ワァ…」「ンショ…」「ヤダッ!!」「ヤーッ!!!」 |
| 小八 | 少数会说人话的，乐观 | 「なんとかなれーッ!!」「ってコト!?」「泣いちゃった!!」 |
| 乌萨奇 | 只说谜之语言，从不哭 | 「ウラ」「ヤハ」「フゥン」「プルルル」「ハァ？」 |
| 飞鼠 | 要人夸、要人安慰 | 「褒めろ」「慰めろ」「ついにやったゾ!!」 |
| 栗子馒头 | 话少，只在吃喝之后叹一口气 | 「ハーッ…」 |
| 獭师父 | 硬派前辈，一两个字；受伤不出声 | 「…悪くない」「いくぞ」「…食え」 |
| 狮萨 | 认真、有礼貌，带冲绳腔 | 「はいさい!」「うれシーサー!」 |
| 古本屋 | 安静、温和 | 「カニ」「どうぞ…」 |

日文用原作台词，中文、英文各自译成当地粉丝熟悉的说法。

---

## 2. 伙伴之间

两只宠物离得近、又都闲着时，偶尔会演一段原作里的来往：一只走过去，两只面对面，各自摆好姿势、做表情、冒气泡，演完各走各的。

| 互动 | 谁发起 | 和谁 | 发生什么 |
| --- | --- | --- | --- |
| 缠人 | 飞鼠 | 吉伊优先，其次小八、乌萨奇、狮萨、古本屋、獭师父、栗子馒头 | 飞鼠扒上去说「褒めろ」。吉伊哭着说「ヤダッ!!」，小八、乌萨奇、狮萨、古本屋各自为难，獭师父和栗子馒头不动声色。没人夸它，飞鼠松手时假哭，说「慰めろ」 |
| カニ挨拶 | 古本屋 | 飞鼠优先，其次吉伊、小八 | 面对面互相做カニ挨拶 |
| 请客 | 獭师父（背包里有吃的时） | 吉伊、小八 | 从自己背包里拿一份吃的递过去，对方当场吃掉、回一点血、开心 |
| 送咖啡 | 栗子馒头 | 两分钟内刚做完除草牌的宠物，吉伊优先 | 递一杯咖啡，对方开心，之后一分钟干活更起劲 |
| 听演奏 | 任何宠物 | 正在街头演奏的小八 | 走到旁边坐下听，时不时鼓掌、说一句；獭师父和栗子馒头安静地坐着听，不鼓掌。小八照常弹，不会被打断，来听的可以不止一只 |

- **只在闲着时：** 干活、讨伐、购物、送礼都优先，互动不耽误正事。被找上的一方也得正闲着：干着活的不会被叫走。
- **坐下的不参与：** 叫它坐下，它就不会自己走开去演，别人也叫不走它。
- **跟随中的：** 只和主人身边的宠物演，走不远。
- **谁都可以：** 不分主人，野生的也算。
- **不重演：** 同一对宠物演过一段后，要隔一阵才会再演这一段——缠人和カニ挨拶半天，请客和送咖啡一整天，听演奏五分钟；和别的宠物照样可以。
- **走不过去就作罢：** 隔着墙、够不着时，对方等一会儿就不等了，这一对也会隔一阵才再试。

---

## 3. 闲着时

宠物闲逛或坐着时，会时不时看看你、看看附近的动物和别的宠物、走几步，或者就待着。每只的习惯不一样，按原作的性格：

- **飞鼠**最爱盯着你看，老远就看过来，一看好几秒，像在等你夸它。
- **吉伊**也常看你，但总是瞄一眼就移开。
- **小八**和**狮萨**有人来就转过头去，小八还会好好看看路过的动物。
- **乌萨奇**停不下来，几乎只顾着到处走，偶尔一瞥。
- **獭师父**更留意周围的动静，很少专门看人。
- **栗子馒头**和**古本屋**大多安静地待着；古本屋抬头看人时，会看很久。

## 4. 打工手册

- **第八页「伙伴之间」：** 口癖气泡、飞鼠缠吉伊、请客和咖啡和カニ挨拶、坐在小八旁边听演奏。
- **手册里的宠物说的就是它在游戏里说的话：** 气泡直接用它自己的台词，所以乌萨奇递礼物时说「ウラ」而不是「どうぞ」，獭师父不喊疼（讨伐失败那一格换成了吉伊，哭着说「ウッ…ウッ…」）。

## 5. 整合包能改什么

和 0.1.0 一样，能调的都在数据包里，默认值由数据生成写出，两个 loader 读同一份。

| 内容 | 路径 | 能改什么 | 何时生效 |
| --- | --- | --- | --- |
| 口癖 | `data/<命名空间>/pet_voice/<宠物>.json`（文件 id 就是宠物的实体 id） | 每个时刻说哪几句（翻译键）和各自的权重；每个时刻说话的概率（闲着那一项是每 tick 的概率）；说完安静多久；附近最多几只同时说；气泡停多久；多远听得见 | `/reload` |
| 台词文字 | 资源包的语言文件，键 `voice.chiikawa.<宠物>.<时刻>.<第几句>` | 改说法、加语言 | F3+T |
| 互动 | `data/<命名空间>/pet_interaction/<id>.json` | 加、删、改互动：谁发起、和谁（实体 id 或 `#标签`，按先后排优先）；对方要在闲逛还是在演奏；对方要刚做完哪种牌；发起方从背包里递什么；对方之后多久更起劲；多远会想到、走多近开演、等多久、演多久、多久不重演、每次张望想到它的概率；每一方的姿势，以及开场、时不时、收尾三个「节拍」 | `/reload`，正在演的不受影响 |
| 闲着时的习惯 | `data/<命名空间>/pet_personality/<宠物>.json` 里的 `idle` | 看玩家、看动物和别的宠物、走几步、待着各自的权重；看多远的人；每件事做多久 | `/reload` |
| 手册页（资源包） | `assets/<命名空间>/manual/*.json` | `say` 写一句台词的翻译键，宠物就在格子里说它 | F3+T |

**说话的时刻：** `tame`（被驯服）、`hurt`（受伤）、`hunt`（出发讨伐）、`paid`（拿到工钱）、`shop`（买到东西）、`gift`（送礼）、`revive`（复活）、`idle`（闲逛）、`cling`（扒着别人）、`clung_to`（被扒着）、`turned_down`（演完没得到想要的，飞鼠要人安慰）、`crab_greeting`（カニ挨拶）、`treat`（请客）、`treated`（被请客）、`given_coffee`（收到咖啡）、`listen`（听演奏：坐下时和鼓掌时）。某个角色没写某个时刻的台词，那时就不说话。

**节拍：** 一个节拍就是三样东西，都可以不写：`animation`（只做一次的动作，按动画名）、`reaction`（表情：`happy`、`hurt`、`confused`、`revive`）、`voice`（上面的说话时刻，按这只宠物自己的台词说）。「时不时」那一拍另写 `every_ticks`：每隔多久来一次，写一个数就是固定间隔，写 `{ "type": "minecraft:uniform", "min_inclusive": 60, "max_inclusive": 160 }` 就是每次在这个范围里重新抽。模型里没有的动画名什么都不会发生，不会报错，所以可以先写上、等模型补上动画。

例：让獭师父也在听演奏时偶尔点点头（假设它的模型里有 `nod` 动画），把 `listen_to_music.json` 里獭师父那一份改成

```json
{
  "pets": ["chiikawa:rakko"],
  "pose": "sit",
  "now_and_then": { "every_ticks": 200, "animation": "nod" }
}
```

完整字段见 [v0.1.1-design.md](v0.1.1-design.md) 第 5.4 节。
