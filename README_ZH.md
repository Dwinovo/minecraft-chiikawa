Chiikawa 模组是一个**把《ちいかわ》的世界带进 Minecraft** 的模组：吉伊、小八、乌萨奇它们会住进你的世界，*每天去公告板领活、赚绿宝石、逛商店*，过上和原作里一样的日子。

> [!TIP]
> 欢迎加入 QQ 交流群 **995178570** 或 [Discord](https://discord.gg/wPkgfst5Z) 交流。更多详情请见[官网](https://chiikawa.dwinovo.cn/zh/)。

## 安装

Chiikawa 模组已发布在 [CurseForge](https://www.curseforge.com/minecraft/mc-mods/chiikawa) 和 [Modrinth](https://modrinth.com/mod/pT971QUb)，在你常用的 Minecraft 启动器中搜索 **"Chiikawa"** 下载即可。目前支持如下版本和加载器：

| Minecraft 版本 | 加载器 | Java |
|---|---|---|
| 1.20.1、1.20.2、1.20.4 | Fabric、Forge | 17 |
| 1.20.6、1.21.1、1.21.4、1.21.5、1.21.6、1.21.7、1.21.8、1.21.10、1.21.11 | Fabric、NeoForge | 21 |
| 26.1.2、26.2 | Fabric、NeoForge | 25 |

Fabric 版还需要安装 [Fabric API](https://modrinth.com/mod/fabric-api)。Chiikawa 模组是双端模组，在联机服中使用时，**服务端与客户端都需要安装**。

## 快速开始

1. **遇到小伙伴。** 吉伊、小八、乌萨奇、飞鼠、栗子馒头、獭师父、狮萨和古本屋会出现在平原、向日葵平原、热带草原、热带高原、沙漠、沼泽和雪原，手里往往已经拿着一件工具。
2. **用食物驯服。** 手持面包、曲奇、苹果、熟肉这类食物右键它，*每次有 30% 的几率*驯服成功，冒出爱心就成了。
3. **下指令。** 潜行时右键自己的小伙伴，在三种指令之间切换：

   | 指令 | 它会做什么 |
   |---|---|
   | 跟随 | 跟在你身边，路过公告板、商店时也会顺手领活、买东西 |
   | 坐下 | 待在原地不动 |
   | 自由活动 | 把现在的位置当成家，在家附近干活、领活、逛商店，还会给你送礼物 |

   直接右键它（不潜行）可以打开它的界面，查看背包、状态和指令。

### 职业

小伙伴干什么活，**由它手里拿的工具决定**：

| 职业 | 给它…… | 它会做什么 |
|---|---|---|
| 农夫 | 锄头 | 种植、收割附近的作物，拔草 |
| 剑士 | 剑，或者角色自己的武器 | 近战讨伐敌对生物，也会保护你 |
| 弓箭手 | 弓（背包里要有箭） | 远程讨伐敌对生物 |
| 音乐家 | 音乐盒（只有小八会） | 演奏你自己放进音乐文件夹的歌 |

### 再往后

- **打工**：放一块劳动公告板，每天日出会贴出工作牌。小伙伴会按自己的职业去领牌，做完就拿到绿宝石，**攒下的钱会自己去商店花**，偶尔也给你买一份礼物。
- **除草证**：放一张考试桌，交一颗钻石就能给小伙伴报名考除草证。考过的级别越高，除草挣得越多。
- **口哨糖**：吹一颗，附近所有的小伙伴一起跟上、坐下或散开去玩。
- **倒下与召回**：小伙伴倒下后会变成玩偶，把玩偶放到蛋糕上就能把它带回来；走丢了就摇一摇铃铛。

第一次进入世界时，你会拿到一本《吉伊的打工手册》，右键就能翻看。更多内容详见[官网](https://chiikawa.dwinovo.cn/zh/)。
