Chiikawa 模组是一个**把 [Chiikawa](https://chiikawa-info.jp/) 的世界带进 Minecraft** 的模组，Chiikawa 里的角色们会来到你的世界里生活，让你在 Minecraft 里体验 Chiikawa 的世界。

> [!TIP]
> 欢迎加入 QQ 交流群 **995178570** 或 [Discord](https://discord.gg/wPkgfst5Z) 交流。更多详情请见[官网](https://chiikawa.dwinovo.cn/zh/)。

## 安装

Chiikawa 模组已发布在 [CurseForge](https://www.curseforge.com/minecraft/mc-mods/chiikawa) 和 [Modrinth](https://modrinth.com/mod/pT971QUb)，在你常用的 Minecraft 启动器中搜索 **"Chiikawa"** 下载即可。目前支持如下版本和加载器：

| Minecraft 版本 | 加载器 | Java |
|---|---|---|
| 1.20.1、1.20.2、1.20.4 | Fabric、Forge | 17 |
| 1.20.6、1.21.1、1.21.4、1.21.5、1.21.6、1.21.7、1.21.8、1.21.10、1.21.11 | Fabric、NeoForge | 21 |
| 26.1.2、26.2 | Fabric、NeoForge | 25 |

Chiikawa 模组是双端模组，在联机服中使用时，**服务端与客户端都需要安装**。

## 快速开始

1. **探索世界。** 在 Minecraft 的世界里四处走走，你会遇到 Chiikawa 里的角色们。
2. **尝试驯服。** 有些角色可以用食物驯服，成为你的宠物，*一直陪伴在你身边*。
3. **指挥行动。** 宠物有多种行动方式：可以跟着你、留在原地，也可以在家附近自由活动，过自己的日子。

宠物具备各种职业，**拿着不同的工具，就会做不同的工作**，比如种田、讨伐或者演奏。

宠物们还会像 Chiikawa 里那样生活：自己去打工赚钱、逛商店、考证书，也会给你带礼物回来。

第一次进入世界时，你会拿到一本《吉伊的打工手册》，右键就能翻看。

更多内容详见[官网](https://chiikawa.dwinovo.cn/zh/)。
